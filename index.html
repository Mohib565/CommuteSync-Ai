02 / Market Landscape

Existing Tools Don't Fit Physical Whiteboards

Current options serve personal student screens or require expensive hardware replacement — leaving ordinary classrooms underserved.

Category Examples Gap in Pakistani Classrooms
Pakistani EdTech Apps Sabaq, Maqsad, Edkasa, Taleemabad Built for personal mobile/tablet study — do not assist live physical whiteboard teaching.
Interactive Smartboards SMART, Promethean, ViewSonic Expensive hardware replacement; requires removing ordinary whiteboards.
Handwriting & OCR Tools Google Lens, OneNote Ink Text capture only — no syllabus context, no verified visual library, no split projection.
CommuteSync AI Software-First Classroom Layer Live whiteboard detection + curriculum filter + verified visuals on existing projectors.

05 / Practical Deployment

Reuse Existing Gear. Add a Kit Only Where Needed.

Default — Existing Classrooms

Software-First Setup

  • Ordinary physical whiteboard
  • Existing classroom projector or TV
  • Teacher's laptop + built-in or USB webcam
Optional — Non-Projector Rooms

Classroom Upgrade Kit

  • Portable projector
  • External USB webcam + mount
  • HDMI & USB connectivity cables
Clear Scope: Laptop is not provided in the kit. A projector or TV is required for classroom display.
